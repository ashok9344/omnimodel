# 🌟 OmniAI Studio (Z-Canva Multimodal AI Platform)

An all-in-one generative AI platform combining **Video Generation**, **Instant Website Building**, **AI English & Study Training**, **Canva Graphic Design**, and **Universal AI Copilot** in a single modern web application.

---

## 🚀 Key Features

### 1. 🎬 AI Video Studio (Text-to-Video & Reels Maker)
- **Prompt to Video Storyboard**: Transform text descriptions into multi-scene cinematic sequences.
- **Dynamic Video Canvas Player**: Live animated 60fps canvas playback with camera motion zoom, atmospheric particles, and synchronized voiceover audio via the browser's Web Speech API.
- **Aspect Ratio Switcher**: 16:9 (YouTube), 9:16 (Shorts/Reels), 1:1 (Instagram Square).
- **Export Options**: Export storyboard scripts, scene visual prompts (for Sora/Runway/Midjourney), or JSON structure.

### 2. 🌐 AI Website Builder (v0 / Prompt-to-Site)
- **Natural Language Website Generation**: Generate complete responsive HTML5 + Tailwind CSS landing pages.
- **Live Multi-Device Sandbox**: Switch between Desktop (100%), Tablet (768px), and Mobile (375px) viewports in real time.
- **Code Inspector & Live Editor**: View and modify source code with live hot-reloading.
- **1-Click Export**: Download standalone `index.html` ready to deploy directly to Netlify, Vercel, or GitHub Pages.
- **Pre-built Templates**: SaaS Platform, Creative Designer Portfolio, Artisan Bistro Cafe.

### 3. 🎓 AI English & Study Trainer
- **🗣️ Spoken English Voice Partner**:
  - Interactive voice conversation using Web Speech recognition (microphone) and neural speech synthesis.
  - Guided scenarios: Job Interview Prep, Casual Cafe Talk, IELTS Speaking Part 2, and Tamil-to-English Bridge.
  - Live feedback on pronunciation, phrasing, and CEFR fluency assessment (A2-C1).
- **✍️ Grammar Doctor & Tamil Insights**:
  - Detects common grammatical mistakes (e.g., *"I did not went"*, *"Myself is"*, *"He don't know"*).
  - Provides in-depth **தமிழ் விளக்கம் (Tamil explanations)**.
  - 3 polished rewrites: Formal, Native Casual, and Executive Business.
- **📚 Smart Study & Quiz Hub**:
  - Feynman technique summaries for Tech, AI, and Language topics.
  - 3D interactive flip flashcards for rapid recall.
  - Interactive Multiple Choice Quiz with score tracking and celebratory confetti!

### 4. 🎨 Canva Graphic Studio
- **Social Media Post & Banner Generator**: YouTube thumbnails, Instagram posts, and Story reels.
- **Live HTML5 Canvas Design**: Real-time typography rendering, gradient palettes, and badge stickers (SALE, NEW, EXCLUSIVE).
- **Export**: Lossless PNG download.

### 5. 💬 Universal AI Copilot
- Multi-persona assistant: Video Director, Web Architect, English Professor, and Canva Designer.
- One-click prompt library with text-to-speech audio narration.

### 6. ⚙️ AI Engine Settings & BYOK
- **Autonomous Built-in Engine**: Works 100% offline and free with high quality generation out-of-the-box.
- **Custom API Key Support (BYOK)**: Connect Google Gemini, OpenAI GPT-4o, or OpenRouter keys directly.
- **Bilingual Interface**: Toggle between English and தமிழ் (Tamil) with a single click.

---

## 🛠️ Tech Stack
- **Frontend Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 + Plus Jakarta Sans & Inter Typography
- **Icons**: Lucide React
- **Voice / Speech**: Web Speech API (`SpeechRecognition` & `SpeechSynthesis`)
- **Effects**: Canvas Confetti

